# Singer 目标加速度扩展

原论文 18 维状态后追加 ENU 目标加速度 `a_t`，内部状态与协方差分别为
21 维和 21×21。控制器仍使用原来的相对位置、相对速度和图像中心状态。
目标加速度仅进入观测器，不向控制律新增加速度前馈。

## 模型与离散化

相对状态定义保持 `p_r = p_u - p_t`、`v_r = v_u - v_t`：

```
dot(p_r) = v_r
dot(v_r) = a_u - a_t
dot(a_t) = -a_t / tau + w_a
```

`tau = target_accel_correlation_time_s`，稳态标准差
`sigma = target_accel_std_m_s2`。各轴驱动白噪声谱密度为
`2 * sigma**2 / tau`，与原 IMU 测量噪声独立。

每个实际 IMU 子步 `T` 内保持 `a_u`，设：

```
beta = exp(-T / tau)
c_v = tau * (1 - beta)
c_p = tau * T - tau**2 * (1 - beta)

a_t_next = beta * a_t
v_r_next = v_r + a_u * T - c_v * a_t
p_r_next = p_r + v_r * T + 0.5 * a_u * T**2 - c_p * a_t
```

完整机动噪声协方差由同一模型积分，包含 `p_r/v_r/a_t` 的交叉项。
小 `T/tau` 时使用级数计算 `c_p`，并以五点 Gauss–Legendre 积分计算
协方差，避免高阶小量相减造成精度损失。`T/tau = 0.1` 的分支只服务于
数值计算，不是飞行门控。

`a_t` 初始均值为零、协方差为 `sigma**2 * I`；零均值不表示目标已知不加速。
视觉测量保持二维中心方位，通过预测产生的交叉协方差更新 `a_t`。
图像宽度、面积和目标尺寸不进入该测量更新。

## 中心量测与三维几何一致性

令 `C` 为相机到机体的旋转，`r` 为相机在机体坐标系的位置，`R(q)`
为机体到 ENU 的旋转。量测模型为：

```
p_c = C.T @ (-R(q).T @ p_r - r)
h(q, p_r) = p_c[:2] / p_c[2]
z = [x_norm, y_norm] = h(q, p_r) + image_noise
```

视觉创新使用 `z - h(q,p_r)`，量测雅可比直接对姿态和相对位置求导。
`image_xy` 仍占用原来的两维存储，但成为代数派生量，不再独立做一阶传播。
初始化、每个 IMU 预测和视觉校正后均重算投影；协方差同步按同一投影的
雅可比映射，包括 Singer 机动噪声引起的图像交叉项。四元数归一化也同步
映射其协方差，避免均值与雅可比采用不同的状态变换。

这两维不再有独立的初始图像方差或手工图像—位置协方差；删除
`initial_image_std` 参数及内部 `image_position_covariance` 初始化选项。
原有相对位置/速度初始协方差仍保留，并决定派生图像的对应不确定性。
从距离初始化消息启动时保留其三维相对状态，输出图像取该状态的投影；
后续中心观测按 DKF 更新。深度非正时沿用原有无效深度处理，未新增距离门控。

## 延迟与接口

保留 50 Hz、D=4 的 DKF 周期；历史检查点、视觉校正及 IMU 回放都维护
完整 21 维状态和协方差。目标机动噪声在每个原始子步按其实际时间重新计算。

现有 `ObserverState` 消息保持不变，`covariance[324]` 发布原论文 18 维
状态的边缘协方差。目标加速度及其交叉协方差保留在内部，未新增反馈话题。

默认候选仍为 `tau=0.7 s`、`sigma=1.0 m/s²`，最初参考较低速的
8 字轨迹选取，不代表已匹配当前更强的目标机动。`sigma` 是稳态标准差，
不是加速度限幅或峰值保证；本次几何修正未调参，这组值尚未通过新闭环试验。

## 验证与适用限制

数学检查覆盖衰减加速度的积分、完整传播雅可比、连续 Lyapunov 噪声积分、
IMU 子步拆分一致性、视觉对加速度状态的更新及延迟回放，以及近距离的投影均值/协方差一致性。原有合成低速闭环
用例继续检查命中、速度和倾角，不能等同于 Gazebo/实机性能验证。

此改动保留现有初始化路径；当前飞行配置仍使用已知尺寸初始化。
目标尺寸未知的实机必须另外明确初始距离先验来源，不能把该初始化当作实测距离。
纯方位测量也不能无条件保证距离、径向速度、目标加速度及 IMU 偏置可分辨。
当前改动不构成完整闭环稳定性或任意机动目标命中保证。
