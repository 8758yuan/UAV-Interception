# 18维DKF：几何一致性与目标机动过程噪声

当前实现保持 `x=[q,p_r,v_r,image_xy,b_gyr,b_acc]` 的18维存储和18×18
协方差，`ObserverState`消息不变。此文件旧版描述的21维Singer加速度状态
未用于当前实现；本次只实施用户确认的几何一致性与独立目标机动噪声。

## 同一三维状态的图像投影

相对状态仍定义为 `p_r=p_u-p_t`、`v_r=v_u-v_t`。`C`为相机到机体旋转，
`r`为相机相对机体原点的位置，`R(q)`为机体到ENU的旋转：

```
p_c = C.T @ (-R(q).T @ p_r - r)
h(q,p_r) = p_c[:2] / p_c[2]
z = [x_norm,y_norm] = h(q,p_r) + image_noise
```

视觉创新为 `z-h(q,p_r)`，测量雅可比直接对姿态和相对位置求导。
`image_xy`是代数派生量，不再独立积分；其对应的独立初始图像方差参数
`initial_image_std`和手工 `image_position_covariance` 初始化选项已移除。

初始化、每个IMU预测、视觉校正及延迟回放都归一化四元数并重新投影。
设该状态映射的雅可比为 `M`，均值与协方差同步按 `x_new=f(x)`、
`P_new=M P M.T` 变换，包含全部图像交叉项及四元数归一化项。
位置均值仍按梯形积分传播，位置对姿态、加速度偏置及IMU噪声的雅可比
同步包含相应的半步加速度项。

原有已知尺寸粗估距初始化来源、相对位置/速度初值及其协方差保留。
初始化消息中的三维状态是先验，图像输出由该先验投影；后续原始图像中心
作为测量校正它。宽度和面积没有新增为持续测量。

## 独立目标机动噪声

真实相对加速度为 `a_u-a_t`。18维模型不新增目标加速度状态，预测均值
仍使用IMU得到的 `a_u`；目标未知机动以独立的连续白加速度噪声表达：

```
d(p_r) = v_r dt
d(v_r) = a_u dt - sqrt(q_a) dW
```

`q_a=target_accel_noise_density_m2_s3` 是各向同性谱密度，单位m²/s³。
它与原有IMU测量噪声独立，必须有限且非负；0表示不计这项机动不确定性。
它不是加速度限幅，也不是控制切换条件。

每个实际IMU子步 `T` 的精确位置/速度噪声积分为：

```
Q_pv(T) = q_a * [[T^3/3 * I, T^2/2 * I],
                 [T^2/2 * I, T     * I]]
```

用预测末端的投影位置雅可比将该噪声映射到18维存储，包含图像—位置、
图像—速度和图像自身协方差；其他核心状态的直接机动噪声为零。
与原有IMU噪声相加得到完整预测协方差。每个原始IMU区间分别计算，
延迟校正后回放仍使用原区间长度；不能按50Hz周期固定增加一次噪声。

参数只在 `config/design_parameters.yaml` 中配置。初值8/9 m²/s³
沿用本次原始录包离线原因隔离的候选值：参考速度2m/s、半径6m的圆周运动，
`a=2²/6`、`sigma_a=a/sqrt(3)`、`tau=6/2`，取
`q_a=2*sigma_a²*tau`。这只是等效白噪声的候选谱密度，不等于实现了Singer
模型，也不表示任意目标的机动统计都相同；该数值尚待新闭环实验验证。

## 延迟、约束与验证边界

50Hz调度、按拍摄时间匹配最近IMU边界、原始区间回放和既有失败原子恢复
保持原结构。非正相机深度仍按数学定义域报无效；没有新增残差门控、距离
阈值、状态机、输出平滑或限幅。控制器与PX4指令通路未增加反馈。

数学及功能检查覆盖完整传播/噪声雅可比的有限差分、几何均值与协方差
一致性、机动噪声积分与IMU分步一致性、连续延迟测量和失败回放恢复，以及
ROS参数、18维消息接口和现有合成闭环回归。

原录包离线回放使用固定的既有飞行轨迹，不能替代新观测器驱动下的Gazebo
闭环或实机测试；即使离线误差减小，也不保证命中或不存在米级校正。
