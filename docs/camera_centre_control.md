# 固定安装相机的观测器几何修正

当前相机光心位于 `base_link` 前方 14 cm，与其原点同高：机体 FLU 坐标下
`r = [0.14, 0, 0]` m。Gazebo 安装位姿显式相对 `base_link` 定义，
控制器和观测器的外参及节点默认值与之保持一致。
机体到 ENU 的旋转为 `R`，相机光学坐标到机体的旋转为 `C`。
本次安装位置调整不改变目标、碰撞体形状、控制律、控制增益和期望图像中心。

## 观测器仍估计机体原点

18 维状态保持 `p_b = p_vehicle - p_target`、`v_b = v_vehicle - v_target`。
初始化和 IMU 平移动力学不改变状态的参考点。图像反投影初始化改为

```
p_b = -R (r + C [x_norm * depth, y_norm * depth, depth])
```

传播图像时，目标光学坐标和光心相对速度分别为

```
target_c = C.T (-R.T p_b - r)
velocity_c = C.T (R.T v_b + omega_b × r)
```

深度取 `target_c[2]`，沿用原平移、旋转图像雅可比。
协方差传播同步包含深度对姿态的导数和杆臂速度对陀螺偏置的导数，
延迟图像校正后的 IMU 回放也使用同一模型。没有增加图像残差门控。

## 撤回光心控制入口和角加速度反馈

此前将控制误差换算到光心，并将里程计角速度差分得到的角加速度作为
光心加速度补偿接入控制律。这条反馈未经闭环设计确认，改后录包出现持续晃动。
该控制入口变更现已整体撤回：控制律直接使用观测器的机体原点 `p_b/v_b`，
不再计算角加速度，也不注入杆臂加速度补偿。

控制入口整体恢复，避免只删去加速度项却保留光心位置、速度变换的部分实现。
图像视线仍来自观测器，阻力、重力、质量及推力映射沿用原实现。
控制参数、物理约束和故障退出流程未调整。

另外，单位视线点积按余弦的数学定义域 `[-1, 1]` 消除浮点舍入误差，
避免完全对准时得到负的 `z1` 并误报 Barrier 定义域错误；Barrier 边界未改变。

## 验证及边界

- 在 0.15 m、0.5 m、12 m 光轴深度，比较非零姿态、平移和转动下的图像预测
  与真实光心投影的中心差分；检查初始化投影往返一致。
- 对零偏移和非零偏移，逐列用有限差分核对图像状态传播雅可比。
- 延迟 DKF 回放覆盖非零安装偏移，配置检查保证控制器和观测器的相机外参一致。
- 控制入口回归检查：机体相对状态直接进入控制律；相邻里程计角速度发生变化时，
  不产生额外加速度反馈。

保留的修改修正观测器中的相机投影几何，不保证控制器以镜头中心撞击目标，
也不保证撞击时图像误差为零。控制律以机体原点定义平移动力学，偏置光心仍会
影响图像视线与机体几何视线的关系。撤回后的晃动与命中表现需要新的闭环录包验证。
公式和功能回归测试不能替代 Gazebo 接触部件与撞击画面的闭环验证。
