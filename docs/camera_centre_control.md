# 固定安装相机的几何与控制修正

当前相机光心位于 `base_link` 前方 14 cm，与其原点同高：机体 FLU 坐标下
`r = [0.14, 0, 0]` m。Gazebo 安装位姿显式相对 `base_link` 定义，
控制器和观测器的外参及节点默认值与之保持一致。
机体到 ENU 的旋转为 `R`，相机光学坐标到机体的旋转为 `C`。
安装偏移按真实模型保留；平移动力学和相对状态仍以机体原点定义。

## 观测器仍估计机体原点

18 维状态保持 `p_b = p_vehicle - p_target`、`v_b = v_vehicle - v_target`。
初始化和 IMU 平移动力学不改变状态的参考点。图像反投影初始化改为

```
p_b = -R (r + C [x_norm * depth, y_norm * depth, depth])
```

传播图像时，目标光学坐标和光心相对速度分别为

```
target_c = C.T (-R.T p_b - r)
velocity_c = C.T (R.T v_b + omega_b × r)
```

深度取 `target_c[2]`，沿用原平移、旋转图像雅可比。
协方差传播按论文固定深度近似：图像对相对位置的雅可比块为零，
图像对姿态的雅可比按式(52)计算，不包含深度对姿态的导数。
杆臂速度对陀螺偏置的导数仍保留，
延迟图像校正后的 IMU 回放也使用同一模型。没有增加图像残差门控。

## 撤回光心控制入口和角加速度反馈

此前将控制误差换算到光心，并将里程计角速度差分得到的角加速度作为
光心加速度补偿接入控制律。这条反馈未经闭环设计确认，改后录包出现持续晃动。
该控制入口变更现已整体撤回：控制律直接使用观测器的机体原点 `p_b/v_b`，
不再计算角加速度，也不注入杆臂加速度补偿。

控制入口整体恢复，避免只删去加速度项却保留光心位置、速度变换的部分实现。
图像视线仍来自观测器，阻力、重力、质量及推力映射沿用原实现。
控制参数、物理约束和故障退出流程未调整。

另外，单位视线点积按余弦的数学定义域 `[-1, 1]` 消除浮点舍入误差，
避免完全对准时得到负的 `z1` 并误报 Barrier 定义域错误；Barrier 边界未改变。

## 2026-10-29：机体原点控制中的相机偏移补偿

本次不恢复光心状态入口或差分角加速度反馈。设 `s = R r`、
`ell = -p_b - s`、`rho = ||ell||`，`n` 为图像反投影视线，
`q` 为随机体转动的设计视线，`P = I - n n.T`，
`b = z1 / (kb^2 - z1^2)`，`lambda = k1 + v_c / ||p_b||`。
状态和投影一致时，真实图像几何满足

```
ell_dot = -v_b - R (omega_b × r)
h = q × n - s × (P q) / rho
z1_dot = q.T P v_b / rho - h.T R omega_b
```

原先视觉加速度使用机体距离，转动反馈未包含杆臂作用。
现在在共用控制器中替换为

```
a_visual = -m b P q / rho
u = lambda (s × n) / (rho + s.T n)
omega1_b = R.T (b h + u)
```

其中 `u` 抵消原机体径向速度参考 `v_d = -lambda p_b` 引起的图像漂移，
满足 `q.T P v_d / rho = h.T u`。该项由已有位置、图像、姿态和安装外参
解析计算，不需要新增传感器反馈、角速度差分或角加速度估计。
`r = 0` 时，`rho = ||p_b||`、`h = q × n`、`u = 0`，恢复原控制公式。

速度参考和其导数继续使用机体距离；SO(3) 姿态反馈、角速度范数饱和、
推力投影和执行器限制保持原结构。普通 DKF 拦截与真值测试共同传入已有
`camera_position_b_m` 外参，不新增参数、经验门控或阶段切换。
光心距离沿用原距离的微米量级数值奇异性检查；漂移公式的分母为零时
走原有无效控制退出路径。这些是公式定义域检查，不是接近距离限制。
当前前置安装且视线在前向有效域内时，`rho + s.T n > 0`。

这会改变非零偏移时的视觉加速度和角速度指令。近距离的视觉反馈可能更强，
不能据此保证执行器能够实现，也不能保证解决全部末段制动问题。
完整导数和饱和残差见 [控制律复核](ibvs_constant_closing_speed.md)。

## 验证及边界

- 在 0.15 m、0.5 m、12 m 光轴深度，比较非零姿态、平移和转动下的图像预测
  与真实光心投影的中心差分；检查初始化投影往返一致。
- 图像对相对位置的雅可比按论文零块检查；姿态块固定深度后用有限差分核对。
  对零偏移和非零偏移，逐列核对其余图像状态传播雅可比。
- 延迟 DKF 回放覆盖非零安装偏移，配置检查保证控制器和观测器的相机外参一致。
- 控制入口回归检查：机体相对状态直接进入控制律；相邻里程计角速度发生变化时，
  不产生额外加速度反馈。
- 控制律检查：零偏移、当前前置偏移和包含高度的偏移；有限差分核对
  Barrier 导数、径向参考的漂移抵消，以及含推力投影、角速度饱和和时变期望
  姿态的完整加权能量导数。该导数保留可能为正的执行残差。

这些修改不保证控制器以镜头中心撞击目标，也不保证撞击时图像误差为零。
控制律以机体原点定义平移动力学，控制性能仍需要新的闭环录包验证。
公式和功能回归测试不能替代 Gazebo 接触部件与撞击画面的闭环验证。
